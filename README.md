📊 Price Tracker UI (Dynamic Price Comparison & Alert System)

A modern, sleek dashboard interface designed to simulate web scraping and price tracking workflows. Users can input product links and set target prices to monitor potential discounts.

🚀 Features
- Add and manage product tracking links dynamically.
- Target price setting and simulated discount notification logic.
- Real-time statistics panel (Active tracks & Discovered discounts).
- Data persistence using browser LocalStorage.
- Dark-mode optimized, modern glass/card UI design.

🛠️ Built With
- HTML5
- CSS3 (Flexbox, Modern Dark Theme styling)
- JavaScript (DOM Manipulation, LocalStorage API, Event Handling)

⚙️ Setup & Run
1. Clone this repository to your local machine.
2. Open `index.html` in your browser or run it via Live Server.
